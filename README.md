# 🦃 Turkey Run: Muckleshoot Escape

A Thanksgiving-themed browser platformer. You are **Gobbles**, a turkey who wandered
into the Muckleshoot Casino Resort the night before Thanksgiving. Run the casino
floor, bounce across slot-machine carpet, dodge chefs and pit bosses, cross the
kitchen (watch the ovens!), and climb the escalator to the 2nd-floor arcade to escape.

## Play

Open `index.html` in any browser — no build step, no dependencies, everything is
one file (canvas + WebAudio beeps).

**Controls**
- ← → / A D — move
- Space / W / ↑ — jump (double-jump!)
- P — pause · M — mute · R — restart after you get gobbled

**Scoring:** 🪙 coins are worth 100, finishing earns +500, and the HUD tracks
your death count (turkeys die a lot).

## Notes

- Pure vanilla HTML5/JS, single file, ~500 lines. Zero external assets.
- All art drawn with canvas primitives; all sound synthesized with WebAudio.
- Made as a Thanksgiving gag game for the family — reference to the Muckleshoot
  Casino Resort's real 2nd-floor guest arcade is affectionate, not affiliated.

Happy Thanksgiving! 🍂
